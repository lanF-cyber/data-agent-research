# CoSQL 实验效率记录

耗时以每轮运行日志为准。中位数代表典型的一问，P90 表示 90% 的问题在该时长以内完成。token 总量按各轮日志汇总，多次模型调用计入同一问。 [逐问耗时与 token](../../evidence/week-03/timing-and-tokens.csv) · [本周报告](README.md)

## 同一批 502 问，两种流程

| 流程 | 单问中位耗时 | 单问 P90 | 总 token |
| --- | ---: | ---: | ---: |
| 同一会话追问 | 4.75 秒 | 7.21 秒 | 3,129,374 |
| 自主查库 + MCP | 9.22 秒 | 21.91 秒 | 14,504,927 |

按日志，自主查库与 MCP 流程每问中位耗时约为基线的 **1.94 倍**，整批使用的 token 约为 **4.64 倍**。Research 以 4 路并发跑完 MCP 批次，实际用时 **28 分 48 秒**。 [502 问运行汇总](../../evidence/week-03/verification.json)
