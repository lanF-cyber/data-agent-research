# 六个问题怎样查证、怎样给分

## 1. 多带一列战役名称，日期答对了

**数据库** `battle_death`。战役表记录战役名称、日期、结果和指挥官。船只记录关联到具体战役，可按地点筛查损失。

**提问顺序**

1. 哪些战役没有船只在英吉利海峡损失？
2. 这些战役的结果是什么？
3. 这些战役的保加利亚方指挥官是谁？
4. 那些战役分别是什么日期？

**Sol 的实际答复与参考结果**

| Sol 返回的战役名称 | Sol 返回的日期 | 参考结果 |
| --- | --- | --- |
| Battle of Adrianople | 14 April 1205 | 14 April 1205 |
| Battle of Serres | June 1205 | June 1205 |
| Battle of Rusion | 31 January 1206 | 31 January 1206 |

参考结果只有日期一列。Sol 给出的三条日期和原库一致，战役名还说明了日期对应谁。按完整结果表得 0 分，按题意得 1 分。 [逐题预测，`dev129_turn4`](../../evidence/week-03/predictions.jsonl)

## 2. 男歌手有四位，参考查询找错编码

**数据库** `concert_singer`。歌手表记录歌手、年龄、国籍和性别。

**提问顺序**

1. Joe Sharp 多大？
2. 有多少位美国歌手？
3. 有多少位男歌手？

第三问的参考 SQL 找 `Is_male = 'True'`，查到 **0 位**。基线用 `Is_male = 1`，也查到 **0 位**。原库实际存 4 条 `T`、2 条 `F`。MCP 版用 `Is_male = 'T'`，答 **4 位**。按完整结果比对，基线得分，MCP 版失分。按题意与原库复评，判定反过来。 [查证 SQL 与理由，`dev215_turn3`](../../cosql/research_config_502/answer_review.json)

## 3. 航班查成零，参考查询也漏了三班

**数据库** `flight_2`。航空公司表存名称和编号，机场表存代码和城市，航班表关联航空公司与起降机场。

**题目**问联合航空有多少班飞往 Aberdeen 的航班。

| 核查对象 | 得到的班次 |
| --- | ---: |
| 连续提问基线 | 0 |
| 自主查库 + MCP | 0 |
| 参考 SQL | 0 |
| 先去掉机场代码两侧的空格，再在原库匹配 | **3** |

两版和参考查询都直接匹配机场代码，漏掉带前导空格的值。原规则会给两版得分，核查后两版都应扣分。 [查证 SQL 与理由，`dev38_turn1`](../../cosql/research_config_502/answer_review.json)

## 4. 「他读几年级」缺了具体人名

**数据库** `network_1`。高中生表记录学号、姓名和年级，朋友表用两个学号登记关系。

| 轮次 | 发给 Sol 的问题 |
| --- | --- |
| 1 | 有多少名学生？ |
| 2 | 有多少名九年级学生？ |
| 3 | 他读几年级？ |

CoSQL 完整对话在第三问前还问过「Kyle 是其中之一吗？」。用于本实验的 SQL 问题回放没有那一轮。参考查询按 Kyle 查出 **12 年级**，基线答 **9 年级**。MCP 版指出上文只谈过四名九年级学生，询问这里指哪一位。原规则没有可比的结果表，题意复评给这一问澄清分。 [给分记录，`dev254_turn3`](../../evidence/week-03/answer-review/decisions.jsonl)

## 5. 查到了 47 班，MCP 表格没有交出来

**数据库**仍是航班库。题目问飞抵 Aberdeen 或 Abilene 的航班一共多少班。

Sol 用终端去掉机场代码中的空格后查到 **47 班**，最后的文字也写了 **47 班**。本轮 MCP 的第三次提交被次数上限拦住，用户只收到文字。原规则按 SQL 和表格判定为未通过，题意复评依据原库核查与实际文字给分。 [逐题预测，`dev28_turn1`](../../evidence/week-03/predictions.jsonl)

## 6. 年龄排错，给了错误的选手编号

**数据库** `wta_1`。球员表存选手编号和生日，生日在库里以整数存储，部分球员缺少生日。

**题目**问最年轻选手的编号。MCP 版答 **200001**，参考 SQL 返回 **200130**。MCP 版把整数生日用普通日期函数解析，排序失效。排除未登记生日的人，按库里的生日从晚到早查，得到 **220156**。两版都失分。 [查证 SQL 与理由，`dev206_turn1`](../../cosql/research_config_502/answer_review.json)
